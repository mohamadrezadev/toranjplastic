## اصول غیرقابل‌مذاکره

- محصول یک پلتفرم شرکتی و B2B برای معرفی خدمات و دریافت استعلام است؛ فروشگاه اینترنتی نیست.
- در نسخه اول سبد خرید، پرداخت آنلاین، موجودی زنده و قیمت‌گذاری خودکار خدمات تزریق وجود ندارد.
- هیچ قیمت، ظرفیت تولید، زمان تحویل، گواهی یا ادعای فنی تأییدنشده‌ای نباید منتشر شود.
- رابط کاربری فارسی، راست‌چین و mobile-first است. آزمون بصری حداقل در عرض‌های 360، 390، 768 و 1280 پیکسل انجام می‌شود.
- نقش پیش‌فرض کاربر Customer است. مجوزدهی و کنترل مالکیت منابع باید در بک‌اند اعمال شود؛ مخفی‌کردن دکمه در فرانت‌اند کافی نیست.
- یادداشت داخلی کارکنان، اطلاعات خصوصی مشتری و فایل‌های غیرعمومی نباید به مشتری دیگر، API عمومی، لاگ یا کش عمومی نشت کنند.
- مستندات موجود و کد فعلی باید پیش از هر پیاده‌سازی بررسی شوند؛ این PRDها مجوز بازنویسی معماری یا افزودن مدل تکراری نیستند.
- تصمیم‌های باز کسب‌وکار باید با برچسب **نیازمند تصمیم محصول** مشخص شوند و نباید به‌صورت پیش‌فرض فرض شوند.

## وضعیت اعتبارسنجی

این اسناد از روی ساختار و مستندات فعلی مخزن تدوین شده‌اند. وجود یک قابلیت در PRD به معنی پیاده‌سازی کامل یا سبز بودن CI نیست. هر قابلیت فقط پس از عبور از معیارهای پذیرش و آزمون‌های مرتبط، «تأییدشده» محسوب می‌شود.
